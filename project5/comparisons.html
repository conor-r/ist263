Key Differences Between Similar Services

One of the hardest parts of learning how to use AWS is that many services sound alike and seem to do the same job. Choosing the right service is important because choosing the wrong one can lead to extra money cost or problems down the line. Below are common comparisons so you know which service to pick.

EC2 vs. Lambda

The main difference between EC2 and Lambda is that with EC2, you rent a virtual server that you set up and manage and pay for as long as it is running, while with Lambda, you upload your code and AWS runs it when something triggers it.

Common scenario: A company wants to create a thumbnail every time a customer uploads a photo. The work is short and only happens when a photo arrives. In this scenario, Lambda is the better choice because it is cheaper and simpler. If the company instead runs a website that must be online 24/7, EC2 is the better fit.

RDS vs. DynamoDB

RDS is a managed relational database. It stores data in tables with rows and columns, supports SQL, and is good at complex queries that combine data from several tables. DynamoDB is a NoSQL database built for fast lookups at almost any scale and doesn't require a fixed table structure.

Common scenario: An online store that needs reports combining customers, orders, and products would fit RDS, whereas a mobile game that needs to instantly save and load millions of player scores fits DynamoDB better.

CloudWatch vs. CloudTrail

CloudWatch tracks metrics and logs and sends alarms so you know how your resources are running. CloudTrail records who did what in your account by logging actions and API calls. CloudWatch is about performance while CloudTrail is about internal security.

S3 vs. EBS vs. EFS

All three of these services store data, but in different ways. S3 is object storage that you reach over the internet, with room for almost unlimited files. Elastic Block Store is like a hard drive that attaches to an EC2 server. Elastic File System is a shared file system that many servers can use at the same time.
