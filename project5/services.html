Popular AWS Services

AWS offers over 200 services, which can feel super overwhelming when first starting out. The good news is that a small group of popular services show up in almost every project. Below is a list of the 7 most popular services and what they do.

Amazon EC2 (Elastic Compute Cloud)

Amazon EC2 is the service that provides users with virtual servers, called instances, that run in the AWS cloud. When setting up your EC2 instance, you get to choose the operating system and how much memory, storage, and processing power you need. You can then launch a server in minutes instead of having to wait weeks for hardware to arrive. EC2 is a great fit for web servers, business applications, and really anything that needs control over a server. It lets you scale up and down as needed and pay for only what you use (EC2 FAQs).

Amazon S3 (Simple Storage Service)

Amazon S3 is an object storage service. You store your files, called objects, inside containers called buckets. You can get them back from anywhere over the internet. S3 can hold very large amounts of data and is most commonly used for backups, images, and data archives. According to AWS, S3's durability is 99.999999999%, which means that your data is extremely unlikely to be lost (S3 FAQs).

Amazon RDS (Relational Database Service)

Amazon RDS makes it easy to set up and run relational SQL databases in the cloud. It supports popular database applications such as MySQL, PostgreSQL, Oracle, Microsoft SQL Server, Amazon Aurora, and more. RDS helps take care of routine work like backups and software patching so you can focus more on your data and applications rather than database administration (RDS FAQs).

AWS Lambda

AWS Lambda lets you run code without setting up or managing any servers. You use Lambda by uploading your code as a function, and Lambda runs it automatically when it is triggered. The computing is serverless, meaning AWS manages it for you. As far as pricing, you are only charged for the time your code actually runs (Lambda FAQs).

Amazon DynamoDB

Amazon DynamoDB is a fully managed NoSQL database that stores data as key-value and document items. It is built for consistent performance at pretty much any size, and it scales automatically as traffic grows (DynamoDB FAQs).

AWS IAM (Identity and Access Management)

IAM controls who can access your AWS account and what their permissions are. It allows you to create users, groups, and roles, then attach permissions to them. A key best practice is least privilege, which means giving people only the permissions they need to do their job and nothing more. IAM is a free service and is the foundation of security in AWS (IAM FAQs).

Amazon CloudWatch

CloudWatch collects metrics and logs from your AWS resources and shows them on dashboards. It allows you to set alarms or take automatic actions when something goes wrong. You can also set billing alarms that warn you when your estimated charges pass a certain amount that you choose (CloudWatch FAQs).
